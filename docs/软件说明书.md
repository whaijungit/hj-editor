# hj-editor 软件说明书

> 版本：0.0.0（开发版）
> 文档更新：2026-10

---

## 1. 软件概述

hj-editor 是一款运行在浏览器里的**沉浸式 Markdown 风格富文本编辑器**，纯前端实现、无需安装、无需账号，打开即写。

特点：

- **所见即所得**：直接输入 Markdown 语法（`#`、`-`、```` ``` ````、`$` 等），回车或闭合标记后自动转成排版效果。
- **沉浸排版**：默认收起标题栏，首屏只有正文与一条极细的大纲标尺。
- **双向导出**：随时导出 `.md` 或独立 `.html`，也支持把内容转成 Markdown 复制到剪贴板。
- **本地存储**：文稿、主题、界面偏好全部存在本机浏览器里，不经过任何服务器。
- **讲课级批注**：内置激光笔，可在页面上自由绘制、标注、截屏。

适用范围：个人写作、笔记整理、技术文档草稿、课堂/会议演示批注。

## 2. 运行环境

| 项目 | 要求 |
| --- | --- |
| 浏览器 | Chrome / Edge 等 Chromium 内核浏览器的最新版本（推荐）；Firefox、Safari 可用，但激光笔截屏不可用 |
| 屏幕宽度 | 桌面端建议 ≥ 1024px；≤ 720px 自动进入移动端布局 |
| 网络 | 打开页面本身不需要联网；在线字体、导出 HTML 中的 Mermaid 渲染、KaTeX 样式表需要联网（ECharts 图表在导出时已渲染成内联 SVG，离线可见） |
| 后端 | 无。所有数据保存在浏览器本地 |

必须依赖的浏览器能力：`localStorage`（草稿快照与界面偏好）、`IndexedDB`（草稿正式存储、导入本地字体）、`Clipboard API`（复制 Markdown）、`matchMedia`（跟随系统主题、减少动效）、`IntersectionObserver`（图表 / 内容的视口懒加载）、`getDisplayMedia`（激光笔截屏，可选）。

### 启动方式（开发者）

```bash
pnpm install
pnpm dev        # 本地开发，默认 http://localhost:5173
pnpm build      # 类型检查 + 生产构建
pnpm preview    # 预览构建产物
pnpm lint       # 静态检查（oxlint）
```

## 3. 界面总览

界面自上而下、自左而右分为五个区域：

| 区域 | 位置 | 说明 |
| --- | --- | --- |
| 标题栏 | 顶部 | 左侧为六个菜单（图标触发），中间为可编辑的文档标题，右侧为激光笔、源码、主题、明暗切换、导出按钮 |
| 正文区 | 中央 | 纸张式排版区域，左侧边缘有宽度拖拽手柄 |
| 大纲标尺 | 正文右侧 | 常驻的细线标尺，每根线对应一个标题，悬停展开目录 |
| 状态栏 | 底部 | 左侧统计数据，右侧为源码 / 专注 / 打字机 / 激光笔状态标记 |
| 浮层 | 覆盖层 | 气泡工具栏、源码抽屉、主题面板、帮助对话框、激光笔画布、提示气泡 |

**默认是沉浸布局**：标题栏首次打开时收起，状态栏保留。标题栏收起后，右上角会出现胶囊按钮用于恢复；按 `Ctrl Shift H` 可一键切换标题栏与状态栏。

### 3.1 标题栏菜单

菜单默认只显示图标，悬停或点击展开，`Esc` 或点击空白处收起。

| 菜单 | 菜单项 |
| --- | --- |
| 文件 | 新建文稿 `Ctrl N` · 导入文件… `Ctrl O` · 立即保存草稿 `Ctrl S` · 导出 Markdown (.md) · 导出 HTML (.html) · 复制 Markdown |
| 编辑 | 撤销 `Ctrl Z` · 重做 `Ctrl Shift Z` · 全选 `Ctrl A` · 清除格式 |
| 段落 | 正文 `Ctrl Alt 0` · 标题 1–4 `Ctrl Alt 1~4` · 引用 `Ctrl Shift B` · 代码块 `Ctrl Alt C` · 分割线 · 无序列表 `Ctrl Shift 8` · 有序列表 `Ctrl Shift 7` · 任务列表 `Ctrl Shift 9` · 插入表格 3 × 3 |
| 格式 | 加粗 `Ctrl B` · 斜体 `Ctrl I` · 下划线 `Ctrl U` · 删除线 `Ctrl Shift S` · 行内代码 `Ctrl E` · 高亮 · 清除格式 |
| 视图 | Markdown 源码 `Ctrl /` · 专注模式 · 打字机模式 · 激光笔 `Ctrl Shift L` · 隐藏标题栏 · 隐藏状态栏 · 隐藏标题栏和状态栏 `Ctrl Shift H` · 主题与排版… · 深色外观 |
| 帮助 | Markdown 语法 · 快捷键 |

带勾选标记的菜单项表示当前已生效。

### 3.2 格式操作入口

本版本采用沉浸式界面，**没有常驻工具栏**，格式操作通过三处入口完成：

1. **气泡工具栏**：选中文字时贴着选区顶部出现，含加粗、斜体、下划线、删除线、行内代码、高亮、清除格式。
2. **标题栏菜单**：段落结构、列表、引用、代码块、分割线、表格等块级操作在「段落」菜单，行内样式在「格式」菜单。
3. **Markdown 语法与快捷键**：见第 6 节与第 10 节。

4. **表格快捷工具条**：光标进入表格后，表格左上角浮出「加表头」按钮，点右侧箭头展开行列、合并、删除等操作，详见 5.7。

文字颜色与段落对齐尚未提供界面入口：从外部导入的 HTML 会保留这些样式，但无法在编辑器内切换。

### 3.3 移动端布局（宽度 ≤ 720px）

- 不渲染标题栏，只在左上角显示一个圆形菜单按钮（☰）。
- 点按按钮弹出侧边菜单抽屉：按「文件 / 编辑 / 段落 / 格式 / 视图 / 帮助」分组，点组名展开，点条目执行后自动收起；点击遮罩或按 `Esc` 关闭。
- 进入激光笔时菜单按钮自动隐藏，避免压住批注工具条。
- 正文按屏幕宽度自适应，正文宽度拖拽手柄不参与布局。

## 4. 文档管理

### 4.1 新建

「文件 → 新建文稿」（`Ctrl N`）会二次确认，确认后清空正文、标题恢复为「未命名文稿」，并删除本机草稿。

### 4.2 标题

标题栏中间的标题可直接点击编辑，`Enter` 或点击别处结束编辑。导出文件与 HTML `<title>` 都使用该标题；文件名中的非法字符 `\ / : * ? " < > |` 会被替换为 `-`。

### 4.3 自动保存与恢复

- 正文或标题发生变化后，停止输入约 0.9 秒自动写入浏览器本地草稿（标题栏右侧显示「自动保存」）；整篇序列化放在浏览器空闲时段执行，不打断输入。
- 正式草稿写 IndexedDB（按顶层块分片，只重写内容变化的分片）；同时保留一份 localStorage 快照，供下次打开时秒开首屏。
- 关闭或刷新页面前会再补存一次。
- 再次打开页面时自动恢复上次的内容与标题。
- 「文件 → 立即保存草稿」（`Ctrl S`）可手动触发，并提示「草稿已保存到浏览器」。

### 4.4 导入

「文件 → 导入文件…」（`Ctrl O`），或把文件直接拖进正文区。

| 文件类型 | 处理方式 |
| --- | --- |
| `.md` `.markdown` `.mdown` `.mkd` | 按 Markdown 解析成富文本 |
| `.html` `.htm` | 取 `<body>` 内容，剔除 `script` / `style` / `link` / `meta` / `title` / `base` 后再导入 |
| `.txt` `.text` | 内容命中两类以上 Markdown 语法时按 Markdown 解析，否则按空行分段、段内换行保留为换行符 |

注意事项：

- 导入会**替换**当前文稿；若正文非空，会先弹出确认对话框。
- 文档标题自动取文件名（去掉扩展名）。
- 其他格式的文件会被拒绝，并提示「仅支持 Markdown、HTML 或纯文本文件」。

## 5. 编辑与排版

### 5.1 段落与标题

支持正文与一至四级标题，通过段落菜单或 `Ctrl Alt 0~4` 切换，也可直接输入 `#` 到 `####` 加空格。

段落对齐（左、中、右、两端）在没有界面入口的情况下会保留导入 HTML 中的既有对齐样式，但无法在界面里切换。

### 5.2 行内样式

加粗、斜体、下划线、删除线、行内代码，以及单色背景高亮（「格式」菜单可开可关，气泡工具栏同样支持）。「清除格式」可一次性去掉行内样式与块级格式。

文字颜色没有界面入口：从外部粘贴或导入的彩色文字会按原色显示并原样导出，但无法在编辑器内改色。

### 5.3 列表、引用与分割线

- 无序列表、有序列表、任务列表（支持勾选与嵌套）
- 引用块
- 分割线

### 5.4 代码块

- 支持 40 余种语言的高亮（JavaScript、TypeScript、Python、Go、Rust、Java、SQL、JSON、YAML、Bash、HTML/XML、CSS/SCSS/LESS、Markdown 等）。
- 光标在代码块内时，右上角浮出操作区：**「复制」按钮**复制整段代码（成功后短暂显示「已复制」），旁边的**语言徽标**点击可切换语言；操作区随代码块滚动出视口时会吸附在顶部继续可用。
- **长代码可折叠**：超过 8 行的代码块，操作区最左侧会多一个**「折叠」按钮**，点击后只留前 3 行（底部渐隐），块下方出现常驻的「展开代码」按钮，滚到任何位置都能点开；直接点击折叠的代码块也会自动展开并落好光标。折叠状态只影响显示，不写进文档——导出的 Markdown / HTML 里始终是完整代码，折叠块编辑时位置会跟着内容一起移动。
- **自动识别语言**：粘贴或导入的文稿里，若代码围栏没写语言（只写 ```` ``` ````），会按代码内容自动补上语言并高亮；识别不出来的保持纯文本。往空代码块、或还没标语言的代码块里直接粘贴代码，也会自动补上语言。
- `Tab` 缩进，缩进宽度 2 个空格。

### 5.5 链接

链接通过粘贴或自动识别生成：

- 粘贴 Markdown 链接语法 `[文字](https://example.com)`，会转成可点击的链接文字。
- 粘贴以 `http://` / `https://` 开头的裸地址时自动识别成链接。

链接在编辑器内不会因单击而跳转，避免误触离开；导出后可正常点击，并带 `rel="noopener noreferrer"`、`target="_blank"`。

### 5.6 图片

两种来源：

1. **本地图片文件**：直接粘贴到正文，或把图片文件拖进编辑器——文件会被读成 Base64 内嵌，随文稿一起保存在本机，插入位置在拖放处。
2. **图片链接**：粘贴 Markdown 图片语法 `![说明](图片地址)`，会自动转成图片节点。

粘贴整段包含图片的 Markdown 时，其中的图片同样会被识别。

### 5.7 表格

- 「段落」菜单可插入 3 × 3 带表头表格，也可粘贴 Markdown 表格（`| 列 A | 列 B |`）自动转化。
- 支持拖拽表格列边框调整列宽。
- 光标进入表格后，表格左上角浮出快捷工具条：
  - 点「加表头」在表格顶部插入一行空表头；已有表头时会叠成双层表头。
  - 点右侧箭头展开面板，可以「左侧添加表头列」，或把首行切换为表头 / 取消首行表头。
  - 调整顺序：上移行、下移行、左移列、右移列（一次移动一位，含合并单元格的表格不支持移动列）。
  - 行列与单元格：在下方插入行、在右侧插入列、删除当前行 / 列、合并 / 拆分单元格、删除表格。
- 工具条随光标离开表格自动隐藏；操作均可用 `Ctrl Z` 撤销。

### 5.8 正文宽度

正文区左侧边缘的细手柄可拖拽调整排版宽度（最小 560px），双击恢复「跟随窗口自适应」。设置会自动保存。

## 6. Markdown 智能输入

直接在正文中输入 Markdown 语法即可，编辑器会在合适时机自动转换：

| 语法 | 输入方式 |
| --- | --- |
| 标题 | `# 标题`、`## 标题`（最多四级） |
| 加粗 / 斜体 / 删除线 | `**文本**` / `*文本*` / `~~文本~~` |
| 行内代码 | `` `代码` `` |
| 链接 / 图片 | 粘贴 `[文字](地址)` / `![说明](地址)` 后自动识别 |
| 引用 | `> 内容` |
| 列表 | `- 项目`、`1. 项目`、`- [ ] 待办` |
| 代码块 | 输入 `` ``` `` 后回车 |
| 分割线 | `---` |
| 表格 | `| 列 A | 列 B |` |
| 行内公式 | `$E = mc^2$` |
| 块级公式 | 空行输入 `$$` 后回车；或 `$$公式$$` |
| 流程图 | 代码块语言选 `mermaid`（或写 `` ```mermaid ``），代码块下方实时出图 |
| 数据图表 | 代码块语言选 `echarts`（或 `` ```chart ``），代码块里写 ECharts 的 option：JSON 或 JS |

补充说明：

- **公式**由 KaTeX 渲染。双击公式可修改 LaTeX（留空即删除）；空公式会显示「点击或双击输入公式」。
- **流程图**在输入后约 0.2 秒渲染，支持 `mermaid` 和 `mmd` 两种语言标识；语法错误时在代码块下方显示错误信息，原代码保留。图表配色随深浅主题切换重画，数据不会上传（Mermaid 以严格安全级别渲染，禁用交互脚本）。
- **数据图表（ECharts）** 的代码块内容支持两种写法：**JSON**（允许整行 `//` 注释、块注释与尾逗号，只做 `JSON.parse`，不执行任何代码）和 **JS**（可声明变量、循环、`map`、模板字符串，也能写 `formatter` 之类的函数，最后交出 option 对象）。在代码块语言里选 `echarts`（或直接写 `` ```echarts `` 后回车），块内填下面这种内容即可出图：

```echarts
// height: 420
{
  "title": { "text": "季度营收" },
  "tooltip": {},
  "xAxis": { "type": "category", "data": ["Q1", "Q2", "Q3", "Q4"] },
  "yAxis": { "type": "value" },
  "series": [{ "type": "bar", "data": [120, 200, 150, 260] }]
}
```

- 数据要先算一遍、或想复用变量时，直接写成 JS 即可——表达式（一个对象字面量）和语句（`option = {…}`、`const option = {…}`、`return {…}`）都认。执行作用域里直接给了 `echarts`（就是 ECharts 命名空间），官网示例里的 `new echarts.graphic.LinearGradient(…)`、`echarts.graphic.RadialGradient(…)` 可以原样贴进来：

```echarts
// height: 360
const months = ['1 月', '2 月', '3 月', '4 月', '5 月', '6 月']
const visits = [820, 932, 901, 1290, 1330, 1120].map((v) => Math.round(v * 1.15))

const option = {
  tooltip: {
    trigger: 'axis',
    valueFormatter: (value) => `${value} 次`,
  },
  xAxis: { type: 'category', data: months },
  yAxis: { type: 'value' },
  series: [
    {
      type: 'line',
      smooth: true,
      areaStyle: {
        opacity: 0.35,
        color: new echarts.graphic.LinearGradient(0, 0, 0, 1, [
          { offset: 0, color: 'rgba(55, 162, 255, 0.55)' },
          { offset: 1, color: 'rgba(55, 162, 255, 0.02)' },
        ]),
      },
      data: visits,
      markLine: { data: [{ type: 'average', name: '均值' }] },
    },
  ],
}
```

- 图表块的约定：首行 `// height: 420` 指定画布高度（160–900px，默认 360px）；宽度跟随正文宽度并在窗口缩放时自适应；ECharts 内核在文档首次出现图表时才按需加载，图表滚到视口附近才初始化实例。**JS 写法会在页面里直接执行**（等价于在文档里跑脚本，只打开可信的文档）；纯 JSON 写法只做解析，不执行代码。中文等非 ASCII 字符写在 JS 里没问题，但别在块里写死循环。
- **粘贴 Markdown**：从网页、代码托管平台等复制的内容若看起来是 Markdown，会自动排版成富文本；按住 `Shift` 粘贴则保留原文。在已有内容的代码块内粘贴代码仍走默认粘贴，不会误转格式。
- **代码语言**：粘贴或导入时，没有语言标识的代码块会按内容识别（`#include` → C/C++、`package main` → Go、`def …:` → Python、`SELECT … FROM` → SQL 等），识别置信度不足则保持纯文本，不猜测。
- 标题超过四级时，粘贴/导入会自动降级到四级显示。

## 7. 视图与阅读

### 7.1 Markdown 源码

「视图 → Markdown 源码」或 `Ctrl /` 打开右侧源码抽屉：只读展示当前内容实时转换出的 Markdown，顶部有「复制」按钮，`Esc` 关闭。这是导出前的检查视图，不参与编辑。

### 7.2 大纲标尺

正文右侧常驻一条细线标尺：

- 每根横线对应一个标题，**线长表示层级**（一级最长，四级最短），当前章节加深显示。
- 悬停标尺展开完整目录面板，点击条目或横线即跳转到对应标题。
- 滚动时自动高亮当前章节（以视口约 32% 高度处为阅读线）。
- 文档没有标题、或正在播放打字演示时，标尺不显示。

### 7.3 专注模式

开启后，光标所在段落保持正常显示，其余段落淡出，用于集中注意力。只影响视觉，不改变内容。

### 7.4 打字机模式

开启后，光标位置会自动保持在视口垂直居中，滚动随输入平滑跟随。

### 7.5 主题与排版

「视图 → 主题与排版…」，或点击标题栏的调色板按钮打开设置面板：

| 设置项 | 可选值 |
| --- | --- |
| 外观 | 浅色、深色、跟随系统 |
| 配色 | 经典（靛蓝）、暖纸（米黄）、森野（青绿）、素墨（黑白灰），每套自带明暗两版 |
| 强调色 | 跟随配色，或从 8 个预设色中选，也可自定义 |
| 正文字体 | 系统无衬线、系统衬线、思源宋体、思源黑体、霞鹜文楷、站酷小薇，以及自行导入的本地字体 |
| 字号 | 14–22px |
| 行高 | 1.5–2.2 |

- 在线字体首次使用需要联网加载（主源失败会自动尝试国内镜像）；加载失败时正文回退到本机字体，面板内可点击「重试」。
- 「导入本地字体」支持 `ttf`、`otf`、`ttc`、`woff`、`woff2`，单文件不超过 40MB；字体文件存放在浏览器 IndexedDB 中，可随时移除。
- 「恢复默认」可还原全部主题与排版设置；设置会自动保存在本机。

### 7.6 隐藏界面元素

- 「隐藏标题栏」「隐藏状态栏」可分别开关，`Ctrl Shift H` 一次切换两者。
- 收起后，右上角出现「标题栏 / 状态栏」胶囊按钮，点击即可恢复。

### 7.7 打字演示与打字反馈

- **首屏演示**：首次打开（或正文仍是示例文稿）时，会在短暂停顿后带光标逐字打出示例内容，新落下的字带一小段发光。「点赞」式的文字发光会沿行尾滚动，形成连续的书写节奏。任意点击或按普通键立即结束演示；带 `Ctrl` / `⌘` / `Alt` 的快捷键不会打断演示。
- 演示期间正文不可编辑，大纲与字数统计隐藏，状态栏显示「正在逐字打出示例文稿…」。
- 系统开启「减少动态效果」（`prefers-reduced-motion`）时，演示与相关动画自动关闭。
- **日常输入反馈**：手动输入时，刚敲下的文字会短暂发光并伴随一束激光从光标处射出；使用中文等输入法时，上屏的一刻才触发反馈，拼音输入过程不闪烁。

### 7.8 状态栏统计

| 项目 | 计算方式 |
| --- | --- |
| 字数 | 去掉所有空白字符后的字符数 |
| 字符 | 正文纯文本总长度（含空格与标点） |
| 段落 | 顶层块级节点数量 |
| 阅读时长 | 字数 ÷ 350，四舍五入且最少 1 分钟 |

右侧标记依次为：源码、专注、打字机、激光笔（处于开启状态时高亮），末尾显示 `Markdown` 标识。

## 9. 导出与分享

| 方式 | 入口 | 说明 |
| --- | --- | --- |
| 导出 Markdown | 文件菜单 / 标题栏下载图标 | 生成 `.md` 文件，使用 ATX 标题（`##`）、`-` 列表、围栏代码块 |
| 导出 HTML | 文件菜单 | 生成**独立单文件 HTML**，内联排版样式，公式已渲染为 KaTeX 结构，代码块已内联语法高亮 |
| 复制 Markdown | 文件菜单 / 源码抽屉「复制」 | 直接把 Markdown 写入剪贴板，便于粘到其它系统 |

Markdown 转换规则（turndown + GFM 插件 + 自定义规则）：

- 下划线 → `<u>…</u>`，高亮 → `<mark style="background-color: …">`，彩色文字 → `<span style="color: …">`
- 代码块保留语言标识（```` ```ts ````）；内容中本身含 ```` ``` ```` 时自动改用四个反引号围栏
- 行内公式 → `$…$`，块级公式 → 独立成段的 `$$…$$`
- 表格、任务列表按 GFM 输出
- 末尾统一补一个换行

HTML 导出的细节：

- 页面自带约 760px 的居中排版样式、表格与任务列表样式、暗色代码块与高亮配色。
- KaTeX 样式表从 CDN 引入；文档中出现 Mermaid 代码块时，才按需从 CDN 加载 Mermaid 并渲染图表（无图表则完全不加载）。因此脱离网络的 HTML 中，公式排版样式与图表可能无法完整呈现，文字与代码不受影响。

## 11. 数据存储与隐私

所有数据仅保存在本机浏览器，不上传服务器，也不包含账号体系。

| 存储位置 | 键 / 库 | 内容 |
| --- | --- | --- |
| localStorage | `hj-editor:draft:v2` | 草稿快照（≤ 800KB 时写入，用于首屏秒开） |
| IndexedDB | `hj-editor` → `draft-meta` / `draft-chunks` | 草稿正文分片（正式数据，容量上限按磁盘配额） |
| localStorage | `hj-editor:theme-config:v1` | 主题模式、配色、强调色、字体、字号、行高 |
| localStorage | `hj-editor:chrome:v2` | 标题栏 / 状态栏显示状态 |
| localStorage | `hj-editor:doc-width:v1` | 正文宽度 |
| localStorage | `hj-editor:laser-shortcuts` | 激光笔自定义快捷键 |
| IndexedDB | 字体库 | 导入的本地字体文件与元数据 |

注意事项：

- 清理浏览器数据、更换浏览器或使用无痕窗口，都会导致草稿与设置丢失。重要内容请及时「导出 Markdown / HTML」备份。
- 本地存储写入失败（如隐私模式、空间不足）时，界面不报错，但不会持久化；导入字体时会明确提示空间不足。
- 图片以 Base64 内嵌，正文中图片较多时会显著增大草稿体积；草稿存在 IndexedDB 中，容量远大于 localStorage 的 5MB，但浏览器配额用尽时仍会写入失败。
- 超过 800KB 的草稿只写 IndexedDB，不再保留 localStorage 快照：打开时需要短暂异步加载（首屏先渲染上次快照或示例文稿）。

### 11.1 长文档的性能与懒加载

正文变长后，真正拖慢输入的通常不是文档模型本身，而是三处重复计算，当前版本已分别处理：

| 开销来源 | 处理方式 |
| --- | --- |
| 每次事务都全量重建装饰（Mermaid / ECharts 预览等） | 装饰放进插件 state，只在文档变化或主题切换时重算；移动光标、改变选区不再遍历全文 |
| 每次按键同步序列化整篇文档并写 localStorage | 停止输入 0.9 秒后保存，`getHTML()` 放在空闲回调里执行；正式数据写 IndexedDB（异步、分片、容量按磁盘配额） |
| 首屏把全文的图表 / 图片全部渲染 | 图表用 `IntersectionObserver` 视口懒渲染（提前 320px 预取），图片带 `loading="lazy"`；ECharts 内核在文档首次出现图表时才动态加载 |

字数统计同样是 O(n)，状态栏改为 300ms 合并计算一次，不再跟着每个按键跑。

仍需注意：ProseMirror 是「真实 DOM」编辑器，不做视图虚拟化。正文超过数万字、或一屏之外挂着几十个图表时，滚动与输入仍会变慢，建议拆分文稿。

## 12. 常见问题

| 现象 | 原因与处理 |
| --- | --- |
| 打开后正文在自动打字 | 这是示例文稿的打字演示，任意点击或按键即可跳过；也可在系统中开启「减少动态效果」永久关闭 |
| 中文输入时没有发光反馈 | 反馈在上屏（输入法提交）瞬间触发，拼音组合过程不闪烁，属正常设计 |
| 截屏提示「当前浏览器不支持截屏」 | 激光笔截屏依赖 `getDisplayMedia`，请使用 Chrome / Edge |
| 截屏失败或画面空白 | 未选择「当前标签页」、授权被拒或系统权限限制，重新按 `S` 并在弹窗中选择当前标签页 |
| 在线字体一直显示加载失败 | 网络不可达或字体 CDN 被拦截，可点「重试」，或改用系统字体、导入本地字体 |
| 导入字体失败 | 仅支持 ttf / otf / ttc / woff / woff2，且单文件 ≤ 40MB；空间不足需先移除旧字体 |
| 「复制 Markdown」提示未授权剪贴板 | 浏览器未授予剪贴板写入权限，可改用源码抽屉手动复制 |
| Mermaid 图表显示错误 | 图表语法有误，下方会给出首行错误信息；修正代码后自动重绘 |
| ECharts 图表显示「配置错误」 | 代码块内容需是合法 JSON 对象，或一段能交出 option 对象的 JS；运行时错误会原样显示，语法没写完则提示检查括号 |
| ECharts 图表一片空白 | 图表只在滚到视口附近时初始化；若仍空白，检查 `series` 是否缺失、容器高度是否为 0 |
| 导出的 HTML 里公式样式 / 流程图缺失 | 该文件依赖 CDN 上的 KaTeX 样式与 Mermaid 库，离线环境下会缺失；ECharts 图表已内联为 SVG，离线可见 |
| 标题只有四级 | 编辑器仅支持一至四级标题，更深层级在粘贴/导入时自动降级 |
| 刷新后内容不见了 | 草稿存在 IndexedDB / localStorage 中，检查是否清理过浏览器数据或使用了无痕窗口 |

### 13.2 关键实现说明

- **扩展装配**集中在 `extensions.ts`：StarterKit（禁用自带代码块，改用 Lowlight 版本）、代码块折叠、颜色、高亮、对齐、任务列表、图片（允许 Base64）、表格（可调列宽）、占位提示、公式节点、Mermaid、打字演示与输入反馈。
- **代码块折叠**由 `codeCollapse.ts` 的 ProseMirror 插件实现：折叠状态按块位置存在插件 state 里，随编辑通过位置映射跟随，被折叠的块加 `is-code-collapsed` 装饰（CSS 限高 3 行 + 底部渐隐），块后挂 widget 形式的「展开代码」按钮；只用装饰、不改文档，因此 Markdown / HTML 导出不受影响，撤销栈也不会多出一步。
- **Markdown 导出**基于 turndown 的 GFM 插件，另加四条自定义规则：下划线、高亮（保留背景色）、彩色文字（保留颜色）、带语言标识的代码块；公式节点通过 `blankReplacement` 还原为 LaTeX。
- **HTML 导出**在序列化前做两步后处理：把公式节点替换成 KaTeX 渲染结果、把代码块按语言重新高亮（视图层的高亮装饰不会被序列化）。
- **Mermaid** 首帧渲染延迟 180ms，按「主题 + 代码」缓存最近 80 个结果；只有文档真正出现图表时才动态 `import('mermaid')`；图表进入视口附近才开始渲染。
- **ECharts** 以 `` ```echarts `` 代码块声明（JSON option，或一段返回 option 的 JS；先按 JSON 解析，不是 JSON 才当 JS 执行，并把 `echarts` 命名空间注入执行作用域），插件在代码块下方挂 widget；`echartsSetup.ts` 按需注册图表类型与组件，首次出现图表时才动态 import（内核不在首屏包内）。视口外不初始化实例，删除代码块或切换主题时 `dispose` 旧实例；导出 HTML 用 SSR 模式渲染成内联 SVG。
- **草稿存储** 走 IndexedDB：正文按顶层块每 40 个切一片，保存时用 FNV-1a 比对分片哈希，只重写变化的分片；localStorage 仅保留 ≤ 800KB 的快照用于首屏秒开，首次运行会把旧版 localStorage 草稿迁移过去。
- **输入反馈**通过自定义 ProseMirror 插件实现：识别单步插入文本事务，给新字加装饰、在光标处生成激光动画；输入法组合期间跳过，`compositionend` 后按「组合起点 → 光标」补一次反馈。

## 14. 已知限制

- 单文档：一个浏览器标签页只维护一篇草稿，多篇文稿需要导出为文件另存。
- 无云端同步与协作，清空浏览器数据即丢失。
- 界面入口不完整：文字颜色、段落对齐、图片链接面板等能力已在扩展层启用（导入内容可正常显示与导出），但当前版本没有提供对应的操作按钮；如需这些入口，需要把配置齐全的完整工具栏重新挂载到界面。
- 表格的行列顺序只能按「一位」逐步上移 / 下移 / 左移 / 右移，暂不支持拖拽整行整列；含合并单元格的表格不能左右移动列。
- 仅支持四级标题；表格不支持单元格底色、跨页表头等高级特性。
- 导出 HTML 依赖 CDN 呈现公式样式与 Mermaid 流程图，离线分享时可能缺样式（ECharts 图表导出为内联 SVG，不受影响）。
- 不做视图虚拟化：ProseMirror 依赖真实 DOM，数万字以上的超长文档滚动与输入仍会变慢。
- 激光笔批注是临时图层，不写入文稿、不可导出为注释数据（仅能截屏保存）。
- 截屏功能受浏览器授权策略限制，部分环境（如受管企业浏览器、无显示服务）不可用。
